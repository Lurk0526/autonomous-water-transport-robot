# 后续实机接入约定（未连接硬件）

当前模块没有串口、ROS 或真实运动发布器。以下约定用于替换模拟输入，需与底盘/机械臂程序共同落实，不表示现有 STM32 固件已经支持。

## 坐标与单位

- 位置原点使用后轴中心，x 向前、y 向左、z 向上；前轮转角向左为正，单位 rad。
- 速度 m/s，加速度 m/s²，角速度 rad/s，时间 s。车体中心与后轴中心若不同，使用明确变换。
- 相机坐标不能直接当车体坐标。真实道路/障碍接入必须有实测安装变换、时间戳及新鲜度检查；当前相机外参不填假值。

## 底盘输入和输出

| 消息 | 必要内容 | 算法怎样使用 |
|---|---|---|
| 运动请求 | sequence、产生时间、失效时间、目标纵向速度、目标前轮转角、停车模式 | 正常限速/限角；紧急停车走单独模式 |
| 执行反馈 | 反馈采集时间、确认的 sequence、实际速度、实际转角、故障/在线状态 | 检查过期和执行偏差，不把命令值当实测值 |
| 定位 | 时间、坐标系、x/y/yaw、速度、不确定度、有效标记 | 路线跟踪、突跳和新鲜度检查 |
| 轮速/IMU原始信息 | 编码器计数或轮速、IMU采集时间与量测/状态 | 为定位融合准备；是否有这些传感器还需落实 |
| 障碍/可通行区域 | 时间、坐标系、占据/未知区域、有效范围、有效标记 | 车体余量、路径候选、受阻停车 |

零速度请求只是一条请求。真实底盘需有可确认的停车/保持行为和通信超时处置；转向角到 STM32 实际控制量的映射由实测标定产生。仿真假设的减速度不能写成实车保证值。

## 机械臂与抓放

监督器发送阶段意图，适配器返回动作 ID、完成状态、实际关节/故障状态，以及可获得的抓取、抬离、承托和松脱证据。动作 ACK 不等于抓住；计时结束不等于承托；对准画面中心不等于获得三维抓取位姿。

当前 mock 明确区分“闭爪动作完成”和“抓取证据存在”，并能独立撤销证据。在实际没有传感手段的字段上保持未知，不能照抄 mock 的 `True`。故障时请求保持当前夹爪、受控停车；实机如何持载和恢复仍需执行端实现与验证。

相机未装车、机械臂改造未定时，可以先完成上述消息解析、记录、模拟适配与单元检查；最终车体外参、手眼标定和关节/承重模型在机构确定后补入。
