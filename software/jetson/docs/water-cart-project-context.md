# 自动运水小车：已确认的任务背景

2026-10-29 回查此前聊天及原有场地方案后整理。下列已确认内容无需再次向用户询问。

## 场地与路径任务

- 场地是试验场西北角的室外砖块路段。
- 工况包括直线、颠簸、转弯、避障、加速。
- 主摄像头的视觉任务围绕该砖路场景的道路/可通行区域、边界和障碍物展开；没有确认采用黑线或色线循迹，也没有确认现场存在标准车道线。
- 数据采集应覆盖日照、树荫、砖缝、路沿、路面不平、振动和运动模糊。普通砖缝或阴影不能直接等同障碍物。

## 车辆与两路视觉

- Jetson Orin Nano 上使用 ROS 2；前轮拉杆转向，后轮驱动，STM32 控制，通过 USB 连接。
- Gemini MAX 是车身主深度相机，用于道路感知、定位建图及避障。
- 机械臂/夹爪相机用于碗的近距离定位，与主摄像头任务分开。
- 整体任务是自动运水及平台上的取碗、放碗；已有机械臂碗识别工作继续复用。
- 曾提出 30 km/h 的整车识别及避障目标；此前没有机械刹车，采用电机反转，尚无实测刹停距离。该目标尚未验收，不能把当前相机约 30 Hz 的数据流验收当作车速能力验收。
