## 建议的第一阶段流程

1. 建立固定在停稳姿态的底盘、机械臂、实际夹爪、工作面和一个碗。首轮不加入底盘行驶任务；若实物悬架形变明显影响机械臂基座姿态，再补充该影响。
2. 核对尺寸、各关节轴线和方向、零位、活动范围、工具中心、夹爪开合及部件碰撞。关节参数与实机控制 ID 一一对应；不直接沿用标准夹爪的末端尺寸。
3. 先用明确的抓取点与动作顺序，验证“到达预抓取位置 → 接近 → 闭爪 → 抬起 → 放下 → 松爪”。该基线用于发现机构可达性、夹持方式和仿真接触问题。
4. 基线通过后，再比较示范学习、强化学习或保留规划控制的方案。候选训练范围为接近动作的修正和夹持时机；是否需要训练整段动作，由基线结果决定。
5. 在后续训练与评估中逐步变化碗的位置、朝向，以及经实测约束的尺寸、质量、摩擦和执行误差。未测参数先标为假设，不能把一次仿真抓起等同于实机可部署。

## 训练接口和验证原则

- 部署策略的输入应来自实机可取得的观测，例如关节位置、夹爪状态、经标定的目标位置；仿真真值可用于早期调试或教师示范，但不能无说明地替代实机感知。
- 动作接口应与现有舵机位置控制能力对应，包含速度、关节范围及动作阶段约束；不预设能直接下发力矩。
- 记录到达、夹持、抬起保持、放置等阶段结果，同时记录掉落、碰撞和关节越界。抬升高度、保持时间及验收成功率，在确认碗、工作面和实机能力后设定。
- 仿真与训练阶段不自动连接或驱动实机。后续实机验证另按已经验证的控制接口衔接。

## 下一步需要的资料

优先由 SolidWorks 使用“文件 → Pack and Go”打包总装及其引用零件、子装配为 ZIP。若方便，再提供完整装配的 STEP 文件，保留可区分的部件。STEP 主要用于几何交换，仍需建立和核对仿真关节、驱动、限位及物理参数。

模型齐全后需要确认实际夹持方式（例如夹外壁或碗沿）、碗与工具尺寸、相机安装位置、工作面位置及训练电脑配置。尚未据此选定仿真软件版本、训练算法或开始训练。
