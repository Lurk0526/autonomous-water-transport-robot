# RTX 4060 道路识别训练指南

这份工程用于自动运水小车的室外道路语义分割。你需要做的是：复制并解压工程 → 在 4060 电脑安装环境 → 小规模检查 → 正式训练 → 把最佳模型带回 Jetson。训练电脑不需要 ROS 2，也不需要连接相机或机械臂。

## 1. 复制和解压

将 `water-cart-road-4060-20261029.zip` 复制到 4060 电脑并完整解压。例如：

- Windows：`D:\water-cart-road-4060`
- Linux：`~/water-cart-road-4060`

建议使用英文目录，保留目录结构。完整包较大，传输盘使用 NTFS 或 exFAT；FAT32 不能放超过 4GB 的单个文件。下载包、解压工程和后续模型文件共预留 **至少 25GB** 空闲磁盘。

包内包含：

| 内容 | 已准备的文件 |
|---|---|
| 完整公开训练数据 | CamVid 701 对，RUGD 7,436 对图像/标签 |
| 已处理标签和清单 | 七类统一标签，训练/验证/测试按视频隔离 |
| 预训练权重 | NVIDIA SegFormer-B0 原始初始化权重 |
| 预热权重 | 本机已完成 5 轮 CamVid 预热的最佳权重 |
| 正式训练配置 | `config/road-train-4060.yaml` |
| 小规模检查配置 | `config/road-train-4060-smoke.yaml` |
| 训练/评估/导出程序 | `tools/`、`vision/road_model.py` |
| 来源、许可与校验记录 | `SOURCES.md`、`BUNDLE_FILES.json`、`reports/` |

完整划分：训练 **5,185** 张，验证 **857** 张，测试 **2,095** 张。模型选择仅使用验证集。不要将测试集加进训练集。

## 2. 安装环境

推荐 **Python 3.11，64 位**。先安装或更新 NVIDIA 官方显卡驱动，并在终端运行：

```text
nvidia-smi
```

应能看到 RTX 4060。Python 的 CUDA PyTorch 包已带运行时，本工程训练不要求先单独安装 CUDA Toolkit。

### Windows：推荐使用命令提示符 CMD

已安装 Python 3.11 后，可以双击工程里的 `INSTALL_4060_WINDOWS.bat` 自动安装。要手动操作，在工程目录的地址栏输入 `cmd` 打开命令行，再依次执行：

```bat
py -3.11 -m venv .venv
call .venv\Scripts\activate.bat
python -m pip install --upgrade pip
python -m pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r requirements-road-4060.txt
python tools\check_training_bundle.py --gpu
```

如果使用 PowerShell，激活方式为 `.\.venv\Scripts\Activate.ps1`。如果激活脚本被系统策略阻止，可以直接使用 CMD，或把后文的 `python` 换成 `.\.venv\Scripts\python.exe`，无需修改系统策略。

### Linux

在系统已提供 Python 3.11 和 venv 模块的前提下：

```bash
cd ~/water-cart-road-4060
bash install_4060_linux.sh
source .venv/bin/activate
```

也可以手动执行：

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r requirements-road-4060.txt
python tools/check_training_bundle.py --gpu
```

上述 PyTorch 版本组合来自 [PyTorch 官方安装说明](https://pytorch.org/get-started/previous-versions/#v280)。不要安装从 Jetson 复制来的 ARM64 wheel，也不要复制 Jetson 的 `.venv`。

GPU 检查应显示 `passed: true`、GPU 名称和显存大小。如果 CUDA 不可用，先解决驱动或 PyTorch 安装问题。工程和模型已在 Orin 上运行验证；本次没有远程访问你的 4060，不能宣称已在你的电脑上验收。

## 3. 检查文件完整性

所有命令都在解压后的工程根目录执行。激活环境后：

```bash
python tools/check_training_bundle.py --full --gpu
```

`--full` 会读取整个工程并核对每个文件的 SHA256，耗时主要取决于硬盘速度。应看到：

```text
"splits": {"train": 5185, "val": 857, "test": 2095}
"passed": true
```

解压包已经包含准备好的标签和相对路径清单，不需要重新下载数据，也不需要先标注自己的照片。

## 4. 先做一次小规模训练检查

```bash
python tools/train_road_model.py --config config/road-train-4060-smoke.yaml
```

这次只执行 8 个训练步骤，使用少量真实图片和真实标签，检查 GPU 前向、反向传播、验证、保存是否都能完成。输出目录：

```text
work/road_training/runs/road-4060-smoke/
```

结束后 `result.json` 应显示 `status: completed`、`steps: 8`、`smoke_only: true`，并有大于零的 `optimizer_updates`。混合精度的偶发溢出会自动降缩放、跳过该次更新并记录；连续异常会停止，避免保存损坏模型。这只是程序检查，准确率没有验收意义。重复运行时使用新输出目录，或先把原 smoke 目录改名保存；程序会拒绝覆盖已完成的运行。

## 5. 正式训练

完整包已经附带 CamVid 预热的最佳模型，默认直接从它开始联合微调，不必再做一遍预热。

```bash
python tools/train_road_model.py --config config/road-train-4060.yaml
```

默认参数：

| 参数 | 设置及含义 |
|---|---|
| 模型 | SegFormer-B0，全部参数可训练 |
| 图像尺寸 | 高 384 × 宽 512，保持宽高比并填充 |
| batch | 2：一次处理两张 |
| accumulation | 2：两次后更新一次，等效约四张 |
| epochs | 20：最多完整学习 20 轮 |
| AMP | 开启混合精度，降低显存使用 |
| workers | 0：兼容 Windows，先保证运行稳定 |
| 数据抽样 | CamVid 25%，RUGD 75% |
| 学习率 | 骨干 0.000006，分割头 0.00006 |
| 随机种子 | 42，记录数据与配置哈希 |

这些是适合小模型的保守起点，实际显存占用和训练时长在你的 4060 上测量后才确定。笔记本的 4060 与台式机功耗不同，不给未经实测的完成时间。

如果出现 `CUDA out of memory`，把配置中的 `batch: 2` 改为 `batch: 1`，`accumulation: 2` 改为 `accumulation: 4`。这样有效批量大致不变。先关闭占显存的软件；如果仍不足，再把 `size` 改为 `[320, 448]`，但要使用新实验目录，并在评估和导出时使用相同尺寸。

训练过程中会输出 loss。loss 是模型与标准答案的差距，整体下降通常表示正在学习，但最后还要看独立验证和测试。每轮保存：

```text
work/road_training/runs/road-4060-v1/
├── best/model/          验证集选出的最佳模型
├── best/trainer.pt
├── last/model/          最近完整一轮的模型
├── last/trainer.pt      恢复训练所需的优化器等状态
├── history.jsonl        每一轮的训练和验证指标
├── run.json             配置、版本和数据哈希
└── result.json          整个训练完成后生成
```

模型只判断图片中是什么区域：铺装地面、松散地面、植被、水面、固定障碍物、人或车辆、天空。它不直接输出转向或油门。

## 6. 中断后继续训练

重新打开终端，进入工程目录、激活 `.venv`，执行：

```bash
python tools/train_road_model.py --config config/road-train-4060.yaml --resume work/road_training/runs/road-4060-v1/last
```

从最后一个完整 epoch 恢复；未保存的半轮会重做。恢复时保持数据、标签、配置和 batch 设置一致。要改变训练方案，创建新配置和新输出目录，从已有模型初始化，而不是混用旧优化器状态。

## 7. 看预测效果和独立测试

训练结束后先查看验证集预览：

```bash
python tools/preview_road_model.py --model work/road_training/runs/road-4060-v1/best/model --manifest datasets/public_road/prepared/camvid-rugd-val.jsonl --output work/road_training/preview-4060 --count 8
```

打开 `work/road_training/preview-4060/contact-sheet.jpg`，左边是原图，右边是模型叠加图。绿色表示铺装地面，棕色表示松散地面，深绿是植被，蓝色是水面，红色是固定障碍物，橙色是人/车辆，浅蓝是天空。

权重选定后，对封存的测试集运行一次：

```bash
python tools/evaluate_road_model.py --model work/road_training/runs/road-4060-v1/best/model --manifest datasets/public_road/prepared/camvid-rugd-test.jsonl --output work/road_training/road-4060-test.json
```

重点看各类 IoU、`paved_precision`、`paved_recall` 和 `non_paved_predicted_paved_rate`。最后一项表示非铺装区域误判成铺装地面的比例，越低越好。mIoU 是各类交并比的平均值，不能单靠一个平均数判断小车是否能自动行驶。

可分别将测试清单换成 `camvid-test.jsonl` 或 `rugd-test.jsonl` 查看各数据集表现；最终模型选择和超参数调整仍只使用验证集。

## 8. 导出并带回 Jetson

```bash
python tools/export_road_model.py --model work/road_training/runs/road-4060-v1/best/model --output work/models/road/road-4060-v1.onnx
```

程序会检查 ONNX 格式，并用相同输入比较 PyTorch/ONNX 的数值。旁边的 `.onnx.json` 应显示 `passed: true`。

训练完成后，把以下内容复制回来：

1. `work/road_training/runs/road-4060-v1/best/model/` 整个目录。
2. 同一运行目录下的 `run.json`、`history.jsonl`、`result.json`。
3. `work/road_training/road-4060-test.json`。
4. `work/models/road/road-4060-v1.onnx` 和旁边的 `.json`。
5. 实际使用的 `config/road-train-4060.yaml`、`config/road-labels.json`。

TensorRT engine 回到 Jetson 后再构建；不要把 4060 上生成的 engine 直接当作 Jetson 可用文件。首次接入 ROS 2 时先显示识别叠加图，再与真实深度和相机标定结合。

## 9. 结果边界与来源

本次公开数据足以开始训练，不要求你现在自采数据。公开数据不包含你们砖路的专门标注，所以训练完先在现场观察阴影、砖缝、路沿和运动模糊下的误判，不能仅凭公开测试集成绩宣称完成整车避障。

当前相机尚未固定，车体安装外参和最终地面过滤留待装车后。RViz 是 Jetson 上查看传感器的界面，4060 训练不依赖它。

模型和数据保留原作者使用条件，详见包内 `SOURCES.md`。完整设计见 `docs/road-training-plan.md`（其中 Jetson 启动脚本仅适用于原板端，4060 请使用本指南的 Python 命令）；ROS 2 入门解释见 `docs/ros2-first-steps.md`。
