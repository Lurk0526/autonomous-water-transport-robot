# 关节模型与遥控抓放基准：测定任务清单

日期：2026-10-25。当前使用遥控机械臂测试，无需先实现自动抓取。

已知参考：碗口直径约 156 mm，高约 60 mm，加到碗口时碗与水总重约 650 g。每轮仍记录实际重量；空碗重量、水重量、夹爪开口和平台尺寸尚需测量。此前电脑预演只验证逻辑，以下项目均须取得实际记录后才能标记完成。

## 任务一：建立机器人关节模型所需的测定

目标：明确各关节怎么转、指令与实际运动怎样对应，以及夹爪和负载会带来哪些限制。

| 优先级 | 测定内容 | 操作方法 | 需要记录 |
| --- | --- | --- | --- |
| 首轮 | 实物关节与控制通道对应 | 遥控一次只动一个关节，拍到哪个部件在运动 | 控制通道/舵机 ID、部件名称、视频编号 |
| 首轮 | 参考姿态和转动方向 | 选容易复现的姿态拍正面、侧面照；在已验证范围内小幅往返 | 参考姿态、当时 P 值（能读到时）、角度参照线、从哪侧观察、P 增加时的方向 |
| 首轮 | 夹爪开口与夹持位置 | 测量可用最大开口、拟夹持高度处各指间净空；空碗试合拢 | 开口 mm、测量位置示意、是否容纳碗、接触碗沿/外壁/底部、是否碰水 |
| 首轮 | 轴心与工具位置 | 结合 CAD 标出关节轴心、相邻轴间距、夹爪中心与相机位置，再用实物核对 | 带标记照片、尺寸 mm、CAD 值/实测值/估计值 |
| 第二轮 | P 值与角度的对应 | 在已验证可用范围内选至少 3 个位置，分别从两个方向接近并测角度 | 目标 P、回读 P、实测角度、接近方向、重复次数；P 不直接当角度 |
| 第二轮 | 本任务可用活动范围 | 记录已成功到达且没有干涉的姿态范围，不顶机械止挡找极限 | 实测可用区间、干涉位置、与其他关节姿态的关系；不要宣称覆盖全部范围 |
| 第二轮 | 延迟、重复性与回差 | 相同小幅动作重复约 3 次，用视频和可用日志观察起动、到达、稳定及反向运动 | 发令/开始/稳定时刻、目标与实测偏差、同点重复误差、反向空行程 |
| 抓放时补充 | 负载下的跟踪和保持 | 空碗可行后逐步增加负载，比较同一姿态的下垂、抖动与保持表现 | 实际总重、关节姿态、保持时间、末端偏移、失稳现象；有测温工具再记温度 |

现有资料的标准对应是：000 底座、001 肩、002 肘、003 腕俯仰、004 末端旋转、005 夹爪。此次以实物核对结果为准，尤其要确认更换 MG23 后的夹爪驱动方式。

**CAD 整理部分由我继续处理：**零件连接关系、候选轴线与轴间距、固定零件合并、工具安装变换、碰撞几何、仿真关节配置。材质和密度可信时可估算质量、重心和惯量，并明确标为 CAD 估算。无需为了填表先拆卸每个零件；未知项保留未知。实际方向、P—角度映射、夹持与承载仍需实测确认。

**完成标准：**控制通道能对应实物，参考姿态可复现，夹爪尺寸有记录，任务相关的关节运动有可核对样本。进一步做动力学仿真时，还要补齐或标定质量、惯量、驱动与延迟，不能仅凭外形相同判定模型完成。

## 任务二：用遥控建立抓放基准

目标：得到一套能重复执行的遥控抓放方法，并测出其成功、失水、耗时和人工修正情况。它是人工操作基准，不代表自动抓取已经实现。

### 固定测试条件

- 底盘停稳；记录机械臂安装高度、平台高度及顶面长宽。用胶带标出车位、碗位和放置点，标注测量基准点。
- 称空碗重量；各轮称起始碗水总重，用总重减空碗重得到初始水重。记录水位描述和是否到碗口。
- 记录夹具版本、接触垫材料、碗外壁干湿、供电条件和操作人。同一组对照尽量保持一致。
- 手机视频要能看到夹爪、碗和台面；记录视频文件名。若能同步导出关节日志，一起保存；无法读取 P 值就留空，先完成视频和尺寸记录。

### 测试顺序

1. **空碗摸索动作。**遥控接近、闭爪、小幅抬离、短距离移动、放下、松爪、撤离，先找到可行的姿态和夹持位置。初次试抬在接物托盘上方、小离台高度进行。
2. **确定关键姿态。**保存起始、预抓取、夹持、抬离、携带、预放置、放稳、撤离这几个状态的视频时间点和可读关节位置。写清人的判断，例如“看到碗偏左，所以先横向修正”。
3. **逐步验证承载。**记录实际载荷，观察滑移、下垂和抖动。等效配重只检查承载；必须记录配重位置，不能把它当作满水动态表现。
4. **满水重复测试。**空碗和承载可行后，以水加到碗口的条件重复同一流程，测失水和时间。每次恢复相同起始条件。
5. **再改变工况。**动作固定后再逐项改变碗的位置、平台高度等；先完成静止底盘抓放，行驶搬运和提前展开另设测试组。

首次摸索动作时的试验与动作固定后的重复测试分开编号。固定动作后建议先做 10 次探索性重复，保留全部失败记录；这用于找问题，不代表已证明高可靠性。任何动作或夹具修改都要更新版本，不能混在同一组统计中。

### 每次必须测什么

| 测定项目 | 记录方式 | 判定要点 |
| --- | --- | --- |
| 能否抓住 | 视频、夹持位置、闭爪状态 | 碗实际离开平台并随夹爪移动；命令发送成功不算抓住 |
| 是否夹稳、承载是否正常 | 试抬及保持阶段的视频 | 记录滑移、下垂、抖动、碰撞和人工补救；有补救不算无修正完成 |
| 是否放稳并松脱 | 放下到夹爪撤离后的连续视频 | 碗已由平台承托，松爪及撤离后不倾倒、不被带走 |
| 总时间和阶段时间 | 从统一视频起点逐段标记 | 记录接近、闭爪、抬起、移动、放下、松爪、撤离；另记人工观察和调整时间 |
| 实际失水 | 比较操作前后碗水总重 | 统一外壁挂水、称量延迟和电子秤精度；称重差先作为估计，不把测量噪声改成零 |
| 人工修正 | 操作后立即补记原因 | 修正次数、发生阶段、看到什么、做了什么；这对应后续自动控制需要的观测 |
| 最终结果 | 每次一行，失败也填 | 全部尝试都计入分母；机械抓放结果与洒水是否合格分开记录 |

失水称量规则必须一致：例如统一处理碗外壁挂水、固定称量时点，并注明电子秤分辨率。接物托盘接到的水可作交叉检查，不与碗的称重差重复相加。外壁挂水、飞溅未收集、测量误差都要备注。

**完成标准：**固定条件和动作版本下，有一组完整的遥控记录，知道哪些姿态可行、失败在哪个阶段、每次用了多久、失水多少、需要几次人工修正。赛事失水阈值未定时，先报告测量值，不自行宣布“合格”。后续自动化既要复现动作，也要替代人的定位和成功确认判断。

## 记录表与提交材料

本目录附有 4 张 UTF-8 CSV 表，可用 Excel 或 WPS 打开；所有数据行留空，没有预填测试结果。

- `01_关节与夹爪记录.csv`：每个关节或夹爪一行，登记对应、参考姿态和任务可用范围。
- `02_关节运动采样.csv`：每次单关节试动一行，记录指令、角度、时刻与误差。
- `03_抓放关键姿态.csv`：每个关键姿态一行，记录视频时刻、P 值与人的判断。
- `04_遥控抓放试验.csv`：每次完整试验一行，记录条件、结果、时间、质量和人工修正。

命名建议：测试组 `G01`，试验 `G01-T01`，视频 `G01-T01.mp4`；修改动作后使用新版本号。每张照片/视频保留原文件，不只留下截图。缺失数据留空，并在备注写“未测”或“无法读取”，不要填 0。

## 第一轮最少需要完成的内容

- [ ] 空碗重量、平台高度/长宽、碗与底座相对位置。
- [ ] 夹爪可用最大开口和空碗接触位置照片。
- [ ] 每个遥控通道对应哪个关节的短视频。
- [ ] 一套空碗抓放动作及关键姿态记录，包括失败尝试和人工修正。

先完成这些即可开始核对模型和动作，不必第一天测齐所有动力学参数，也不需要先实现自动抓取。
