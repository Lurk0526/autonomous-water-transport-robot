# 待补材料

> 2026-11-02 运行工程更新：已补 Jetson 软件、相机/ROS 感知、训练工具、模型索引及本机仿真证据。下面保留此前资料整理时的逐项状态；同日软件与相机更新以 [接入记录](runtime-import-20261102.md) 为准，未完成的实车验证继续有效。

优先补能让第二版模型独立打开、让当前状态可见的材料。代码按用户安排，由另一台机器上传即可。

## 第一批：模型与实际装配

1. **第二版整车的 SolidWorks Pack and Go ZIP。** 从 `成品车.SLDASM` 出发，打包关联零件和子装配；记录 SolidWorks 版本及实际使用的配置。当前只有一份整车总装和机械臂配件，未确认包含车架、轮端、悬架、转向、传动等全部依赖。
2. **同版整车的 STEP 导出。** 用于没有 SolidWorks 的机器检查几何。注明毫米单位及装配层级；STEP 不替代原生文件和装配约束。
3. **当前实物照片。** 整车四周、俯视、底部、机械臂底座、四爪接口及电控布置。说明四爪是否已装上、是否能开合，照片对应哪个车架版本。
4. **改造件。** 团队修改的钢适配件、机械臂安装板、夹具接口及悬架连接板的原生模型/工程图；未单独建模可先补尺寸草图。

SolidWorks 官方说明 [Pack and Go](https://help.solidworks.com/2022/english/SolidWorks/sldworks/c_Pack_Go_Ovw_WPDM.htm) 用于收集相关零件、装配、图纸及引用。打包后在新文件夹中打开检查“缺失引用”，能更直接确认依赖是否齐全。本环境尚未执行这项重建检查，不能列出确定缺失的零件名。
