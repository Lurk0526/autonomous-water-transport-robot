# 任务约束

| 项目 | 当前要求或记录 | 待确认口径 |
| --- | --- | --- |
| 任务 | 起点自动夹碗，复杂路面自主运输，终点放碗 | 完整评分原文与终点台面尺寸 |
| 持碗 | 全程由机械臂夹持，不能使用车载碗托或给碗加盖 | 碗形、湿接触摩擦、持碗姿态的承载验证 |
| 载荷 | 最大碗径约 156 mm，碗水合计约 650 g | 实物尺寸、空碗/水质量、水面余量；附件另计 |
| 路面 | 水泥、砂石、砖块，包含障碍和转弯 | 坡度、障碍尺寸、道路宽度、照明及允许的地图信息 |
| 速度 | 测速点需达到 30 km/h 级别；允许绕障、取放及颠簸段减速 | 原截图为 >30 km/h，后续口述 ≥30 km/h；载水条件、测速区和制动距离待课程原文确认 |
| 底盘 | 自制铝型材框架；不能直接采用 RC 成品底盘 | 标准悬架/轮端模块的课程允许范围 |
| 尺寸 | 旧截图长、宽、高分别大于 0.5 m | 展开状态及附件是否计入，需回看完整任务书 |
| 预算 | 历史内部总上限 12,000 元；P1 另出现课程 10,000 元口径 | 实际课程额度、已花费用及收据；不能混为一个已确认限额 |
| 人工操作 | 保留遥控调试、接管和急停；自动任务按自主流程执行 | 课程允许的介入时机；功能实现与测试记录 |

速度、电机额定值和供应商宣传参数均不代表本车实测结果。未确认口径不能作为验收已通过的依据。
