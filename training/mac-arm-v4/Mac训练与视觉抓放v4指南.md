# Mac v4 训练、视觉接近与调参指南

## 1. 本轮做什么

首要目标是停车后650g水碗的抓起、保持和放回。先把可解释的闭环控制作为基线，再让PPO只输出小范围TCP位置残差；如果PPO不能在独立数据上超过基线，就保留基线。主摄定位平台、车辆选取可达停车位置、腕摄寻找碗，是独立可审查的视觉接近流程。暂不把整套系统从图像到方向盘、关节命令混在一个大策略中训练。

原型中按公共行程强制指定各指节角度的模型已经退出运行入口。当前使用CAD销轴构建32个铰链、12个闭环连接和一个公共滑架执行器；公共滑架固定后仍保留8个被动自由度。被动关节弹性与阻尼尚未实测，这部分是模型假设，不能把本地通过当成真实机构辨识完成。

本轮本地证据及完整限制见 `validation/本地修复与验证报告.md`；调参过程中的失败没有从统计中删除。

## 2. 安装与运行

保留旧版本及其outputs。把整个ZIP解压到全新的普通目录，进入 `mac-arm-v4` 后执行：

```bash
bash setup.sh > Mac安装日志.log 2>&1
bash Mac执行本轮.sh --large-if-ready
```

不要在Rosetta终端运行。安装器会核验SHA256、解压内置Python3.12 arm64，并从60个离线wheel安装固定版本；不需要Docker，不需要英伟达CUDA，也不需要重新下载GUI。若失败，先查看并回传 `Mac安装日志.log`，不要自行升级MuJoCo/Torch。

仅验收、不启动正式训练：

```bash
bash Mac执行本轮.sh
```

每次自动建立 `outputs/mac-v4-check-时间戳`，不能覆盖以前的输出。大批物理场景可能耗时较长，日志每20个场景打印进度。Mac接电、关闭低电量模式，保留至少8GB可用磁盘空间。

## 3. 自动流程和停止条件

1. 单元/回归测试及inspect，记录源码、模型和配置指纹。
2. Mac上比较CPU2/4/6进程，再比较相同环境数的MPS；只有MPS采样加更新的实测吞吐至少快10%才选MPS。比较失败会停止训练，避免静默换设备。YOLO默认CPU；可显式加 `--vision-device mps` 另测。
3. 新开发集112000–112099共100场景，新验证集113000–113199共200场景；停车X/Y各±25mm，车身角度±15°，1mm定位噪声、80–180ms执行器延迟、泡沫摩擦0.5–0.9。范围为可配置实验条件，不是实际停车分布测量。
4. 视觉接近先跑120000起3场景，全部完成后再跑121000起20场景。主摄、停车、腕摄、完整物理抓放分别计数，识别成功不等于抓放成功。
5. 两组机械臂基线各需观察成功率≥95%，没有硬接触/力越界/闭环误差/碰撞/数值异常，且测试与文件指纹一致，才准入2万步残差PPO。移动流程的门槛单独报告，不会因为主摄看到了碗就认定整车策略通过。
6. 2万步best与final同开发集评估，保留全部训练故障和所有开发评估。若守卫失败或开发成功率退化超过2个百分点，停止扩大；否则从已核验final续训额外8万步，实际步数可能因整批rollout略高于10万。

114000–114199共200场景保留为最终盲测，本轮自动脚本不使用。参数或策略选择结束后再对选定版本运行一次，不要反复挑选最好的盲测结果。95%是观察成功率准入条件，不是总体成功率或实机成功率保证。

MPS只加速策略网络的矩阵计算，物理、碰撞与环境进程仍在CPU。64×64小网络可能CPU更快；测速结果会写进 `execution-selection.json`，不会只凭GPU利用率判断加速。

## 4. 查看GUI与相机

查看单次基线抓放（计算完成后回放；空格暂停、R重放、Q退出）：

```bash
bash run.sh gui --experimental-model --seed 98000
```

只看CAD：

```bash
bash run.sh gui --experimental-model --cad-only
```

单独做完整视觉接近与物理抓放：

```bash
bash run_mobile.sh platform-evaluate --episodes 3 --seed 124000 --output outputs/platform-check-124000
bash run_mobile.sh gui --episode outputs/platform-check-124000/episode-124000
```

GUI是保存状态的回放，不会连接实机，也不是独立于记录的又一次成功统计。`--localization-only` 只检验开车和找碗，不能作为抓取成功率。旧 `evaluate` 移动命令保留供历史调试；v4正式流程使用 `platform-evaluate`。

## 5. 摄像头和停车策略

主摄从已配准深度中提取水平平台，按显式尺寸/朝向先验建立带不确定性的保守边界；先去平台附近，不能把平台中心当碗位置。接近过程中最多两次根据新观测更新路径，粗定位停车候选把平台搜索中心放在臂坐标X=215/220/225mm处，给未知碗偏移留工作空间余量，车辆用连续自行车运动学积分，不瞬移、不原地旋转。停车容差8mm，并需连续静止确认。

当前主摄候选安装点为车体坐标 `[0.40,0.30,0.75]m`，为避开手臂而移到侧上方。该安装点不是实机标定结果。平台最大宽/长0.4m、朝向与里程计对齐也是显式仿真假设；图中30–40cm描述的是高度，不能当作实测宽度。

腕摄固定在servo004之前的支架上，servo004旋转不会让相机跟着转。当前候选支架：光学坐标横向偏移45mm、绕Y转−12°；观察TCP在台面上方140mm。整臂执行最多10个有限观察姿态，包含纵向−80/−40mm及横向偏移，避开夹爪遮挡并进入可达工作区。不是新增主动云台。

腕摄使用包内已有 `target-bowl.pt` 分割权重、相机参数、已知碗口尺寸和测得台面高度估计位置；未检测或定位不可信就停止。实际渲染的光照、反光、遮挡与实机有差异，当前少量仿真检测不代表现实识别精度。

抓放交接使用腕摄结果并冻结该次估计，真实RGB流程不会暗中切回碗真值。机械臂独立训练中的带噪位姿观测会在闭爪前平均24次新观测；这是未来视觉定位接口的观测契约，不能当成RGB视觉精度验证。当前尚未做抓放过程中的持续视觉跟踪。

主摄仿真使用RGB-D；若实机主摄没有深度，需另做标志板/已知尺寸几何或多视图定位。实机前必须测相机内参、支架外参及手眼关系，不能照抄上述虚拟安装坐标。

## 6. 抓放控制与奖励

公共滑架从−3mm开口慢闭，先接触的一侧不会让整个机构立即冻住。只允许有限追加公共行程；对向泡沫原始接触力各≥0.5N、总力≥8N连续100ms才确认承载，随后调节公共预载到总泡沫力16N。单指8N、总25N、滑架40N和硬接触限制均保留，原始瞬时越界不会被低通滤波掩盖。

16N等数值是仿真监督假设，不代表已经测得真实舵机夹力；策略观测不直接含这些接触力。实机必须用已验证的电流/力估计或其他等效承载确认，才可移植监督器。

抓起保持工具完整朝向，避免冗余关节转动造成载荷冲击。首次真实触台即停止下降、清空延迟命令并撤掉滑架积累预载；台面连续承托充分后才松爪，不能靠大力压台面获得“支撑成功”。成功条件保持：离台至少30mm、稳定保持2秒、倾斜≤0.2rad，放回位置误差≤10mm，足够台面支撑、夹指脱离且连续稳定0.5秒。

奖励事件只发一次：试举+10，验证保持+20，完整放回+100；失败−200，另有随时间积分的时间/倾斜/残差/动作变化代价及折扣一致的距离势函数。失败不能同时拿完成奖励，不按夹得越紧奖励，不奖励支撑冲量。PPO输出3维TCP残差，整体上限5mm，各阶段收紧，支撑和松爪阶段归零；单公共夹爪控制由监督器负责。

## 7. 如何调参

先查看失败的 `failure_reason`、微步窗口及RGB/mask，不先改奖励权重。

| 现象 | 优先检查 | 保留条件 |
| --- | --- | --- |
| 单侧接触而对侧无力 | 腕摄估计、夹爪中心、公共开口与泡沫厚度 | 不添加独立手指电机 |
| `waypoint_unreachable` | 停车位置、观察姿态、IK残差与关节限位 | 不放宽可达误差伪造成功 |
| `hard_contact` | 碗外形、抓高、CAD碰撞分解和泡沫安装 | 不删硬指节碰撞 |
| `foam_contact_force_limit` | 瞬时力、接触几何、预载积累、数值接触 | 不调高力上限掩盖问题 |
| 放回仍悬空 | 腕摄高度、有限下降搜索和首次触台停降 | 不用碗真值直接放到桌上 |
| `closed_chain_loop_error` | 销轴装配、步长、约束求解和被动关节 | 不改为碗与爪焊接 |
| 主摄无平台 | 深度、遮挡、安装点和平台尺寸先验 | 不提供真实平台中心给规划器 |
| 腕摄无碗 | 支架偏移/角度、整臂搜索和模型置信度 | 保留识别失败原图 |

调参复制 `config/train.yaml` / `config/mobile.yaml` 为新文件，一次改一个因素，用新输出目录和相同开发种子对比，保留失败分母。更改后不要加载旧配置训练出的策略。示例：

```bash
bash run.sh --config config/你的新配置.yaml diagnose --seed 112003 --output outputs/你的实验
```

真实标定优先级：公共滑架行程和指节开合录像/位置、650g成功动作的舵机脉宽及时间、关节负载下跟踪、泡沫厚度/摩擦/压缩特性、空碗质量和碗剖面、两路相机标定、平台尺寸和实际停车统计。塑料柔性、水晃动、防洒指标与整车颠簸应另立实验，不以刚体水碗抓放通过替代。

## 8. 回传

无论通过、停止或报错都保留本轮完整outputs。填写 `Mac回传说明.md`，执行：

```bash
bash 打包回传.sh
```

把生成的 `.zip` 和 `.zip.sha256` 一起传回。具体交给另一台电脑助手的说明见 `本轮需要回传的文件.md`。
