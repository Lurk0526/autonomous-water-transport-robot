# 请交给Mac上的助手：v4实验与回传任务

请在新解压的 `mac-arm-v4` 目录操作，保留旧版本，不连接真实机器人。不要自行升级依赖、关闭碰撞、降低650g载荷、增加独立夹指控制或放宽成功标准。未执行的项目写“未执行”，不要用旧版成绩填本轮结果。

## 执行

```bash
bash setup.sh > Mac安装日志.log 2>&1
bash Mac执行本轮.sh --large-if-ready
```

该脚本先验收和CPU/MPS测速；未准入会停止，这是需要回传的诊断结果。不要跳过训练门槛强行长训，也不要反复跑114000–114199盲测挑最好结果。若只要求验收，去掉 `--large-if-ready`。

## 必须保存

- 完整本轮 `outputs/mac-v4-check-*`：所有日志、测试、基线100/验证200、诊断、CPU/MPS测速、门槛结论及阶段决策。
- 全部 `platform-evaluation.json` 和每个episode：主摄平台RGB/深度/JSON、停车候选/重规划、腕摄搜索RGB/mask/JSON、定位交接、物理抓放trace和回放。识别、停车、定位、抓放要分别统计。
- 如果开始PPO：完整run、config-used、TensorBoard、monitor.csv、所有eval、best/final/checkpoint、source-integrity与rollout-guard-summary；包括中断与失败轮次。
- 修改过的源码/配置/碰撞资产以及修改原因；安装日志；一段GUI观察说明。可另存屏幕录像至该次run目录，会自动收集。

## 打包

复制 `Mac回传说明模板.md` 为 `Mac回传说明.md`，填写实际结果。然后：

```bash
bash 打包回传.sh
```

默认收集所有 `outputs/mac-v4-check-*`。单独手动实验若不在这些目录，要显式追加：

```bash
bash 打包回传.sh --run outputs/mac-v4-check-实际时间 --run outputs/platform-check-124000
```

工具自动包含本轮源码/配置及启动脚本、模型清单与碰撞分解、结果原图、策略和日志；记录系统与包版本、改动文件、SHA256和ZIP自检。跳过虚拟环境、wheel负载和未改变的CAD网格，避免重复传大包。根目录的 `*日志*.log` 会收集，其他安装错误日志可放进本轮run的logs。

最终把相邻 `Mac回传/` 中的 `Mac机械臂v4-回传-时间戳.zip` 与同名 `.zip.sha256` 一起传回。不要只交HTML摘要或成功视频。

若安装尚未生成可用Python，手动ZIP打包安装日志、完整终端错误、`Mac回传说明.md` 与已有outputs；不要因此丢弃错误证据。
