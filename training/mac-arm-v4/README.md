# Mac v0.4：同步四爪、水碗抓放与双相机接近

给 M2 Pro / 16GB / 原生 arm64 macOS 的完整离线实验包。载荷保持 650g，四爪由一个公共滑架驱动，碗为自由刚体。包含原始 STEP、CAD 网格、闭环连杆、碰撞分解、已有碗分割权重、MuJoCo GUI、CPU/MPS 测速、分阶段残差 PPO 和回传工具。

本轮按用户新授权做了本地小规模物理与视觉复测。实际结果、失败轮次及适用范围见 `validation/本地修复与验证报告.md`。本地小样本通过不代表实机成功率已达到95%。

Mac 解压到新目录，进入 `mac-arm-v4`：

```bash
bash setup.sh > Mac安装日志.log 2>&1
bash Mac执行本轮.sh --large-if-ready
```

先读 `Mac训练与视觉抓放v4指南.md`。流程先测新场景、检查碰撞和力异常，再决定是否运行2万步与累计约10万步；不会直接启动30万步。MPS仅用于网络，MuJoCo物理使用CPU；按Mac实测吞吐选择。

主摄用已配准RGB-D观测平台，车辆连续接近并停稳；腕部相机通过整臂搜索，以现有YOLO分割碗，再交接物理抓放。没有识别时保留失败，不用碗真值替代检测。主摄平台提取是深度几何算法，尚不是平台语义网络。腕相机安装角度/45mm偏移是仿真候选，需要实物支架与手眼标定。

机械臂源码、CAD模型和训练配置指纹用于防止混用旧结果。v4不加载v1/v2/v3策略。真实执行器、被动关节、泡沫参数和深度相机尚未标定；当前车辆为运动学近似，水仅计入总质量，不模拟流体。不含真实车辆或机械臂命令接口。

结束或失败后，按 `本轮需要回传的文件.md` 执行 `bash 打包回传.sh`。

本轮借鉴的开源方法与实际采用范围见 [开源项目借鉴与取舍](docs/开源项目借鉴与取舍.md)。
