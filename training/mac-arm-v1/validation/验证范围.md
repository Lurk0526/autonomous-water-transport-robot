# v0.1 验证范围

本包完成环境、真实几何转换、候选训练任务和操作入口交付。**没有达到预定 95% 取放成功率，也没有完成真实 MG23 动态联动和实机验证。**

- 真实 STEP 的 41 个独立部件、171 个叶子实例完成网格转换，41 个 B-rep 检查均有效。
- Linux aarch64 / CPU：11 项回归检查通过，SB3 环境接口检查通过，真实 CAD 原生 GUI 3 秒启动检查通过。
- PPO 两个独立进程完成 1024 步短训，再加载 checkpoint 追加 256 步。模型、优化器、日志和 checkpoint 链路通过；这不是充分训练。
- 独立控制基线：种子从 10000 开始，200 次，114 次成功（57%），未达到 95%。所有停车目标通过本候选模型的端点 IK 检查，但仍有路径接触/跟踪失败，说明可达不等于能完成任务。
- 失败分布：33 次非预期碰撞、10 次跟踪误差过大、5 次闭爪接触缺失、23 次抬升保持失败、4 次承托不足、11 次最终放置失败。保留原始每回合结果，不删除失败样本。
- 仅做短训/续训的策略，在相同种子起点的 20 次检查中 11 次成功（55%）；不能据此宣称优于基线或已收敛。
- 可达扫描：±8 cm、±45°组合的 125 个位姿中，本候选 IK 接受 100 个；这不是经过路径碰撞验证的实机工作空间。
- Mac 离线依赖：42 个 wheels 的 SHA256 均与官方 PyPI 匹配，56 条适用依赖关系核验通过；Python 运行时为 Mach-O arm64，SHA256 与官方发行元数据匹配。
- MacBook 实际安装、GUI、内存和速度尚未在 Mac 主机执行；本地 Linux 结果不能替代该验收。

对应原始记录：`baseline200/evaluation.json`、`smoke-evaluation/evaluation.json`、`tests.log`、`gui-native.log`、`train-final.log`、`resume-final.log` 和 `summary.json`。

下一步优先校验关节刚体分组和 MG23 真实联动、实测泡沫与舵机动态，再调接触高度/闭爪行程并做 PPO 对照。降低随机范围只可用于明确标记的课程训练，不应把缩小后的成功率冒充原范围或现场成功率。
