# Mac 机械臂 v4.2 离线复测包

本轮验证针对 650 g 水碗的完整抓起、保持和放回。机械臂带载时，优先保证名义轨迹，超出可达范围的末端修正量在原速率范围内回退。带载关节在物理子步内平滑跟踪目标。视觉流程的筛选和实际执行共用 48 mm 抓取高度。独立标定板工具用于检查腕摄安装的系统误差。

在 Apple Silicon Mac 上解压，进入 `mac-arm-v4.2` 目录，在原生 arm64 终端执行

```bash
bash setup.sh > Mac安装日志.log 2>&1 && bash Mac执行本轮.sh --large-if-ready
```

脚本离线安装，再进行 Mac 验收。通过训练门槛后会比较 CPU 和 MPS 吞吐，再启动 2 万步训练。只做验收时去掉 `--large-if-ready`。结束后执行 `bash 打包回传.sh`。

查看 [Mac 复测与训练指南](Mac复测与训练指南.md)、[本轮优化与验证](validation/本轮优化与验证.md) 和 [回传清单](本轮需要回传的文件.md)。
