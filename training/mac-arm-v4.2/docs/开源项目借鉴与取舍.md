# 开源项目借鉴与本项目取舍

2026-11-19查阅以下原始仓库/代码。这里借鉴结构和方法，自行适配用户CAD；没有把这些项目的夹爪、底盘、力参数或成绩当作本车证据。本轮未新增ROS、Gazebo、Mink或robosuite运行依赖，Mac继续使用已锁定的MuJoCo环境。

| 项目与原始入口 | 借鉴内容 | 本项目处理 |
| --- | --- | --- |
| [Reuleaux底座选位](https://github.com/ros-industrial-attic/reuleaux/tree/master/base_placement_plugin) | 先用可达性信息筛选底座位置 | 使用本臂IK、完整抓放路径及实际车辆避碰筛选有限停车候选；粗定位阶段给未知碗偏移留工作区余量。该老ROS项目已迁到attic，本轮借鉴方法，不安装它 |
| [robosuite组合控制器](https://github.com/ARISE-Initiative/robosuite/blob/master/robosuite/controllers/composite/composite_controller.py) | 分组件控制、明确移动模式下目标参考关系 | 移动与抓放分阶段；停稳、重新观测和可达性复核后才抓取；观察姿态与抓取IK分支分开初始化，关节仍连续限速运动 |
| [Mink腕摄LookAt示例](https://github.com/kevinzakka/mink/blob/main/examples/arm_ur5e_wrist_cam_lookat.py) | 用整臂关节改变相机视线，配合姿态与速度约束 | 本轮保留固定相机安装变换和有限整臂观察姿态，目标来自平台观测及真实分割；不按碗真值旋转虚拟相机。Mink的QP视觉伺服是后续可做的对照，尚未接入 |
| [MuJoCo Menagerie Robotiq模型](https://github.com/google-deepmind/mujoco_menagerie/blob/main/robotiq_2f85/2f85.xml) | 可视网格与碰撞几何分开，真实连杆/被动关节/软垫分别建模 | 用户四爪仍按自己的STEP销轴建闭环、保留被动自由度和一个公共执行器；硬指节做凸分解，泡沫单独建模。不会复制两指夹爪拓扑或其弹簧/摩擦数值 |
| [mobile-rl](https://github.com/robot-learning-freiburg/mobile-rl) | 移动操作应同时考虑导航和操作的可行性 | 作为后续移动策略对照；本轮先固定可解释的停车与抓放基线，再训练小残差，不直接迁移其机器人模型/策略 |

当前细节来自本地失败诊断，而不是“开源项目也这样做，所以已经正确”：初始主摄视野可能被自身手臂挡住；原停车候选240mm使碗偏移后落到臂工作区边缘；观察姿态的冗余关节分支可能无法直接热启动抓取IK。相机候选扫描、停车候选调整和连续姿态衔接分别保留复测结果。

当前规划仍是有限候选集与采样路径检查，不是Reuleaux完整逆可达图或Mink约束QP，也不是全局最优证明。未来需要扩大停车/台面/视觉扰动时，应增加可达图、目标不确定性筛选和有界重新停车；不靠缩小车体、删除碰撞或超出实机能力的关节运动扩大可行域。

碰撞数值背景参考 [MuJoCo官方碰撞文档](https://mujoco.readthedocs.io/en/3.3.5/computation/)。本地复现的3.3.7圆柱碗底/桌面浅接触深穿透问题，用同包络96边碗底修复并写回归测试；这是本项目复现结果，不是声称官方文档确认了该具体缺陷。
