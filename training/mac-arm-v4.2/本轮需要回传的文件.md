# 给 Mac 助手的回传清单

保存本次运行新建的完整 `outputs/mac-v4.2-check-时间戳`。若脚本提前停止，保留已完成的逐例 JSON 和本次日志，一样可以回传。

- 保存 `Mac安装日志.log`、单元测试日志、`inspection.json`、`workflow-status.json` 和最终 `training-decision.json`。
- 保存 `known-failures24`、`baseline-dev100`、`baseline-validation200` 下的计划、每例试验记录和总表，以及配对比较、修复复查、训练准入结果。
- 保存 `mobile-first3` 和已运行的 `mobile-dev20`，包含停车轨迹、主摄深度、腕摄 RGB 与掩码、完整抓放轨迹和分割模型指纹。
- 如有测速或训练，保留 CPU/MPS 测速、选用设备、实际步数、rollout 失败记录、开发评估、best/final/checkpoint、配对结果和 TensorBoard 日志。
- 如有 `waypoint_unreachable`，另运行一次 `bash run.sh diagnose --seed 失败种子 --output outputs/diagnose-失败种子`。打包时显式包含这个目录。

复制 `Mac回传说明模板.md` 为 `Mac回传说明.md`，填实际数字和观察。运行

```bash
bash 打包回传.sh
```

如另存了诊断、GUI 或使用自定义 `--output` 目录，用 `--run` 指定每一个需包含的目录，例如

```bash
bash 打包回传.sh --run outputs/mac-v4.2-check-实际时间戳 --run outputs/diagnose-112002
```

将生成的 `Mac回传/Mac机械臂v4.2-回传-时间戳.zip` 和同名 `.zip.sha256` 传回。打包器自动包含源码、配置、启动脚本、系统信息及结果文件。
