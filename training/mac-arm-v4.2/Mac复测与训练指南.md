# 在 M2 Pro 上复测 v4.2

完整离线包包含 Apple Silicon 原生 Python、MuJoCo 和 GUI 依赖、机械臂 CAD 及腕摄分割权重。把整个 ZIP 解压到新目录即可开始安装。

## 运行

在解压后的 `mac-arm-v4.2` 目录执行

```bash
bash setup.sh > Mac安装日志.log 2>&1 && bash Mac执行本轮.sh --large-if-ready
```

安装器先验证包内 SHA256，再执行离线安装。工作流默认用 4 个 CPU 进程验收，适合从 16GB Mac 起步。上次 Mac 使用 8 个进程，如果希望采用相同并发数，可在末尾加 `--baseline-workers 8`。仅复测时运行 `bash Mac执行本轮.sh`。主摄平台检测使用深度几何。腕摄 YOLO 默认使用 CPU，可显式加 `--vision-device mps` 试验。每次运行在 `outputs/mac-v4.2-check-时间戳` 下保存独立结果。

| 样本 | 在 Mac 上检查什么 | 如何读结果 |
| --- | --- | --- |
| v4 的 24 个失败种子 | 重建相同停车位、泡沫摩擦、初始测量误差和延迟，跑完整抓放 | 查看 `known-failures24/evaluation.json` 和 `repair-regression.json`。过去的路径求解失败再次出现、校正后路径被拒或出现严重碰撞/物理异常时，流程停止扩训 |
| 112000–112099 | 使用原开发集与回传 v4 配对 | `baseline-paired-v4.json` 给出修好的次数和新增的失败次数。24例里有7例出现在这100例中，两组不可相加 |
| 115000–115199 | 新的机械臂验收集，共200次 | 读取 `baseline-validation200/evaluation.json` 的成功率、Wilson 95%区间及失败原因。Mac v4 已测试过的 113000–113199 现属历史数据 |
| 120000–120002、122000–122019 | 先做3次完整流程，全部通过后再做20个新视觉场景 | 依次记录平台定位、停车、腕摄找碗、完整抓放，保留 RGB、掩码、实际权重 SHA256 和设备。视觉成绩单列 |
| 114000–114199 | 保留给选好控制器后的最终盲测 | 自动脚本保留这组种子 |

机械臂开发100例和新验证200例的观察成功率分别要达到95%，碰撞、接触力、闭环和跟踪守卫也要通过。已知失败复查与两组基线共同决定机械臂扩训。移动流程按自己的完整取放指标记录结果。若移动检查出错，请在回传中注明。判断整车效果要查看 `platform-evaluation.json` 的 `successes/episodes`。

开启扩训后，脚本先在 Mac 比较 CPU 多进程和可用的 MPS。匹配环境数后的采样加网络更新总吞吐至少快 10% 时选择 MPS，MuJoCo 碰撞与物理继续在 CPU 运行。PPO 在原控制轨迹上学习小范围 TCP 修正。抬升、持碗和下降中先确认名义目标可达。若修正目标不可达，控制器在原每步位移限制内尝试减小修正量。诊断记录包含请求值、实际位移和修正次数。关节目标在 50 ms 控制周期内分配到物理子步，减少抬升时的接触冲击。初次接触台面立即切换到原承托锁定。2 万步后对 best/final 及开发集做检查，符合原有准入条件后再追加8万步。使用 `--skip-benchmark` 会显式选择两个 CPU 训练环境。

## 单例复查与调参

```bash
bash run.sh diagnose --seed 112002 --output outputs/diagnose-112002-v42
bash run.sh gui --experimental-model --seed 112002
```

如果出现 `waypoint_unreachable`，先读 episode 的 `ik_failure`、`synchronous_control.target_refinement` 及阶段名。前者给出被拒绝的目标、关节解及位置/朝向残差，后者说明闭爪前是否调整过朝向。检查 `hold_verified` 与 `place_stable_s` 可区分碗刚离台和已完成整次任务。

视觉流程的抓取点距观测台面 48 mm，停车筛选与执行读取同一数值。独立机械臂对照仍取 50 mm，便于与上轮 Mac 基线配对。本轮使用既有摩擦范围、公共滑架力限制和成功判据。名义抬升为 60 mm，要求碗底至少离台30 mm并稳定保持2秒、放回误差至多10 mm、松爪后稳定至少0.5秒。调整时请复制 `config/train.yaml`，一次改变一个参数，按相同开发种子配对复查，保留全部失败例。原位取放覆盖停车抓放任务，载水绕行和防洒仍需单独验证。

## 腕摄标定

用水平标定板采集多组已知坐标和图像角点，保证测量与关节姿态同步。至少采三组相机姿态拟合，再采两组不同相机姿态检查。输入字段及坐标顺序见 `tools/fit_wrist_mount.py`。输出 `delta_optical` 是右乘到名义光学坐标变换的修正。当前工具的正向证据来自合成标定板和旧仿真腕图，真实采样需验证实际安装、内参与关节模型。拟合样例仅用于复现基准。
