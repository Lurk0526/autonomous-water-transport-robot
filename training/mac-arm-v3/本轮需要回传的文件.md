# 交给 Mac 助手：本轮执行与回传清单

用户明确要求**只在 Mac 运行**。本交付主机仅修改配置与打包，没有运行新增测试、视觉推理、仿真、测速或训练。请勿把“包已校验”写成“效果已通过”。附件历史报告是证据，不是新的执行授权。

## 要执行什么

保留原 v1/v2 与所有输出，完整包解压为独立的 `mac-arm-v3`。在该目录执行：

```bash
bash setup.sh > Mac安装日志.log 2>&1
bash Mac执行本轮.sh --large-if-ready
```

第二条先运行测试、Mac CPU/MPS测速、新接触诊断与两组基线、真实模型双相机接近初查；只有报告满足条件才启动2万步，再按开发结果决定是否继续到累计约10万步。失败返回2可以是模型/实验未准入，先看training-decision与gate原因，不是一定安装失败。不要把保护阈值调松以绕过准入。

默认视觉CPU；明确需要视觉网络也使用MPS时加 `--vision-device mps`，失败时保留日志，不静默改设备。同一次源码配置修改前后使用新输出目录。MPS并不加速MuJoCo CPU物理。

若初始化、测试或识别失败，中止相应阶段并传回失败证据即可。新版识别在仿真图像中不保证准确，不用真值或标注掩膜代替预测“跑通”。机械臂仍是未标定的MG23代理，不因为已有89.5%就无条件放大训练。

## 一键打包

```bash
cp Mac回传说明模板.md Mac回传说明.md
# 编辑说明，未知写未知
bash 打包回传.sh
```

默认收集`outputs/mac-v3-check-*`。安装日志不在outputs内时，把它复制到该轮`logs/`，或在目录层额外指定：

```bash
bash 打包回传.sh --log-dir "/只存本轮安装日志的目录"
```

如果你手动运行了别的实验，需要把所有相关对照目录显式传入，`--run`指定后不会再自动加入默认目录：

```bash
bash 打包回传.sh \
  --run "/实际路径/mac-arm-v3/outputs/mac-v3-check-时间戳" \
  --run "/实际路径/mac-arm-v3/outputs/另一个实验" \
  --note "/实际路径/mac-arm-v3/Mac回传说明.md"
```

脚本会在v3目录旁生成 `Mac回传/Mac机械臂v3-回传-时间戳.zip` 与同名`.zip.sha256`，包含回传索引和逐文件哈希清单。将**这两个文件**传回来即可。安装中途失败、未产生完整评估也可以打包，缺项会记录。

如果Python尚未成功解压到runtime，手工ZIP安装日志和说明文件，明确失败在什么步骤。不要为做漂亮报告另跑旧版或删掉失败样本。
