# Mac v0.3：双相机识别、车辆接近和抓碗实验包

面向 M2 Pro / 16GB / 原生 arm64 macOS。包含完整离线环境、现有 `target_bowl` 分割权重、主 RGB-D 粗定位、前轮转向车辆接近、候选停车与机械臂路径筛选、腕部单目精定位、停稳后抓放、接触异常诊断，以及 CPU/MPS 测速和分阶段 PPO 入口。

**新增模块只做过源码静态检查，效果验证由 Mac 执行。** 本次没有在打包主机运行测试、视觉推理、仿真、测速或训练。上一轮 Mac 实测为 v2 的179/200（89.5%），不是 v3 结果。

先读 [Mac视觉接近与训练v3指南.md](Mac视觉接近与训练v3指南.md)，Mac 上执行：

```bash
bash setup.sh
bash Mac执行本轮.sh --large-if-ready
```

该命令先检查与评估，只有源码/配置一致、接触异常和成功率满足检查条件时才启动2万步，再按开发结果决定是否继续至累计约10万步。不是直接从头跑端到端大策略。MPS 与 CPU 用 Mac 实测速度选择，MuJoCo 物理仍在 CPU。

主相机找碗、靠近停稳、腕相机精定位后抓取使用真实分割网络预测；没有检测就停止，不回退碗真值。台面几何预先已知，相机内外参、车辆尺寸与执行器参数均是仿真假设。当前车辆为平面自行车运动学模型，停稳后交接 MuJoCo 机械臂接触动力学，尚非整车动力学/水晃动/实机闭环。MG23 联动仍需按实机成功动作标定。

回传要求见 [本轮需要回传的文件.md](本轮需要回传的文件.md)。保留旧 v1/v2 目录，v3 不加载或续训旧策略。
